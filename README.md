# 月月的工作台 · 像素森系 v10.0

> **天地通，年月通，日事通，万事皆成！**
> 一个可直接「添加到 iPhone 主屏幕」的 PWA 个人工作台：治愈森系绿 + 暖米黄护眼纸感，像素手绘图标，数据永久保存，支持系统级锁屏推送。

---

## 一、一眼看懂

| 维度 | 说明 |
|---|---|
| 形态 | PWA（`display: standalone`），iPhone/Android/桌面浏览器全屏运行，**没有底部 Tab、没有悬浮窗** |
| 布局 | 左侧固定导航 **200px ⇄ 可折叠 72px**（手绘叶片纹理 + 波点 + 线条小狗），右侧内容区 |
| 导航顺序 | 今日中枢 · 植物养护 · 灵感补给站 · 财富工坊 · 时光胶囊 · 智能提醒中心 · 成就殿堂 · 设置 |
| 视觉 | 像素风 + 森系手绘融合；苔藓绿 `#5A7A4A` / 奶油米黄 `#FDF8EC`（60%）、橡木棕 `#C4A882` / 鼠尾草绿 `#A8BBA0`（30%）、像素红 `#D64550` / 暖橙 `#E8A87C` / 蜂蜜黄 `#F0D58C`（10%）；文字深棕 `#3D2C1B`（**全程不用纯黑纯白**） |
| 护眼 | 三档护眼模式（暖纸 / 更暖 / 夜间深色）+ 字号三档 + 动效开关 |
| 数据 | **本地优先**：IndexedDB 永久保存（可申请持久化存储）；配置 Supabase 后自动升级为云端同步 + Storage 存图 |
| 推送 | `Notification.requestPermission()` + `PushManager.subscribe()` + `web-push` + VAPID + Service Worker `push` 事件 → **手机锁屏可见** |
| 体积 | 零运行时依赖，Vite 按需构建，前端 gzip **约 60KB**（上限 500KB） |
| 安全 | 全站 HTTPS · CSP · XSS 过滤（`esc()` + `sanitizeRich()`）· RLS 行级安全 · 密钥只存 Vercel 环境变量 |

## 二、功能总览（对应规格 19 节）

### ① 今日中枢
- 待办列表：内容 / 时间 / 日期 / 完成状态；右侧编辑按钮可改内容与时间日期；**完成即锁定**（显示「已锁定」标签），**可取消完成后再编辑**；顶部 `+ 添加待办`。
- 植物养护自动汇总：到期的换水/浇水任务自动出现在待办里，标题形如 **`观音竹换水(含营养液)`**；在植物页完成养护记录后，该待办**自动标记完成**（双向同步，取消完成会撤销标记）。
- 每日学习三项（英语 / 理财 / 新闻）：点击即完成，**每日可重置**；点「英语单词」进入 5 新词 + 5 复习的单词学习页。
- 五账户速览 + 今日开销速览（当日可变支出合计）+ 今日金币明细。

### ② 植物养护（两级页面）
- **预设 8 株**：水培大蒜 / 水培碗莲 / 水培洋葱（每 2 天换水）、观音竹（2 株）/ 发财树 / 玛丽亚（每 10 天换水 + 营养液）、土培茉莉 / 土培月季（每天早晨浇水）。
- 一级页「花园」：卡片显示名称 + 种植日期 + 成长状态图标 + 最新照片缩略图 + 距今天数 + 今日养护提醒，底部 `+ 添加新植物`。
- 二级页「单株成长日记」（独立路由 `#/plants/detail/<id>`）：顶部名称/日期/状态/编辑/养护倒计时；相册九宫格（点击全屏、左右滑动）；时间轴日记（日期 + 描述 + 照片 + 操作标签 换水/浇水/施肥/修剪/观察 + 动态反馈 发芽/生长/开花/休眠/茂盛）；底部**成长分析**（种植天数 + 最近记录距今 + 记录频率 + 情绪价值反馈，如「玛丽亚今天精神抖擞，你照顾得真好！」）；返回按钮回花园。

### ③ 灵感补给站
- 子分类可切换：好书推荐 / 经典名句 / 电影推荐 / 知识解读 / 理财串珠 / 好词好句摘抄。
- 内容在右侧内容区直接完整展示（标题 + 正文 + 配图 + 来源 + 标签），配图自动抓取（Open Library 免密钥，失败回退本地森系像素封面）；底部保留**「阅读原文」**按钮。
- **好词好句摘抄**独立子页：手动添加（文字 + 出处/作者 + 分类标签 励志/哲思/爱情/古诗词/生活），支持分类筛选、关键词搜索、**一键导出 TXT**。

### ④ 财富工坊
- 记账：可变支出 / 固定支出 / 收入三类，含金额 + 类别 + 日期 + 备注 + 照片（可选）；顶部快速类别按钮（餐饮/交通/日用品/房租/水电/工资…）。
- 花销分析：周/月支出趋势折线图 + 月度支出结构饼图；收入管理：月收入趋势 + 收入结构饼图 + 本月收支结余。
- 固定支出：预设项目（名称 + 金额 + 扣款日期），支持编辑 / 删除 / 跳过一次 / 提前扣款；到日期自动扣减 + 推送通知。
- 购买清单：名称 + 价格 + 数量 + 日期随时可改，显示小计与购买状态；点「购买」自动记账并从日常账户扣减，已购移入「购买历史」。
- 心愿兑换清单：1 金币 = 1 元，10/20/50/100 四档，从心愿账户扣减。
- 实时金价：国际/国内金价 + 涨跌幅 + 最高/最低 + 7 日 / 30 日走势图；打开板块自动刷新 + 下拉刷新；目标价触发站内通知。

### ⑤ 时光胶囊
- 情侣日志：文字 + 多张照片九宫格；**开始时间可随时更改，系统自动重算**；顶部显示「在一起 XXX 天」+「距离下一个纪念日 X 天」。
- 备忘录：同构，支持照片。

### ⑥ 智能提醒中心
- 生日提醒（姓名 + 农历/公历 + 提前 N 天 + 每年重复）/ 定期联系（联系人 + 频率 + 具体时间 + 提前提醒）/ 自定义提醒（事项 + 日期 + 周期 + 提前天数 + 备注）。
- 提醒列表按「待处理 / 即将到来 / 历史」分页；**日历视图**有提醒的日期显示标记。
- 通知机制：到点或提前 N 天时**同时**触发系统级推送（锁屏可见）+ 站内横幅；统计看板显示「本月已处理 X 项」「即将到来 X 项」。

### ⑦ 成就殿堂
- 本周金币明细（待办 / 内容学习 / 省钱 / 组合技）柱状图 + 近 7 周金币走势图。
- 成就徽章墙（连续 7 天全勤 / 累计阅读 50 篇 / 省钱小能手 / 植物达人记录 ≥30 天 / 金币百枚 / 相伴百日…），解锁时动态弹出特效。
- **每周日自动生成「成就卡片」**（本周金币总数 + 最高单项 + 连续打卡天数），一键保存或分享。

### ⑧ 单词学习
- 每日推送 5 个新词 + 复习前日 5 个词；每个单词配备读音（点喇叭）、跟读（录音 + 回放对比）、例句及精准中文翻译；内置 60 词词库，可自行添加。

### ⑨ 金币激励机制（无漏洞版）
| 项目 | 规则 |
|---|---|
| 省钱奖励 | 当日可变支出 0 元 → 0 币；1–15 元 → **2 币**；16–30 元 → 1 币；31 元以上 → 0 币；**每周封顶 14 币** |
| 晨间套餐 | 待办全部完成 + 已读满 4 篇 → **+1 币/日** |
| 阅读套餐 | 已读满 4 篇 + 收藏 ≥ 1 条 → **+0.5 币/日** |
| 记录套餐 | 情侣日志/备忘录单次满 100 字且含插图 → **+0.5 币/日** |
| 待办 / 学习 | 完成一条待办 +0.2（日上限 2）；完成一项每日学习 +0.2（日上限 0.6） |
| 结算 | 各类**独立计算、无总封顶**；满 10 / 20 / 50 / 100 弹窗庆祝，满 100 弹出「恭喜！可以购买首饰啦！」 |

### ⑩ 五账户体系（独立，严禁混合）
| 账户 | 规则 |
|---|---|
| 日常账户 | 月额度 = **当月天数 × 50 元**，月初自动重置；月额度为唯一硬性上限，耗尽当月停用；仅用于餐饮/交通/日用品/娱乐 |
| 固定支出账户 | 预设项目自动扣减，**不占日常额度、不计入省钱奖励** |
| 收入账户 | 手动记录（工资/兼职/投资/红包/其他），独立统计，不参与奖励 |
| 金币账户 | 任务奖励获得（1 金币 = 1 元），**仅用于心愿兑换** |
| 心愿账户 | 金币兑换后转入，不占月额度 |

### ⑪ 雅思备考专区（灵感补给站 → 雅思备考）
侧栏入口数量不变（仍是 8 项），雅思体系作为「灵感补给站」的二级页接入：`#/inspire/ielts`。

| 子模块 | 内容 | 路由 |
|---|---|---|
| 课程体系 | **4 门课 × 3 单元 × 3 节 = 36 节**：听力精讲 / 阅读精讲 / 写作精讲 / 口语精讲。每节含讲解正文（400–900 字）、本课要点 3–6 条、**4 道原创单选题**（作答后逐题给出解析、自动判分、记录最高分、得分 ≥60 算完成） | `#/inspire/ielts/course[/<课程>/<课>]` |
| 备考文章 | **30 篇原创**：考试结构、评分标准、听力/阅读/写作/口语四项技巧、备考时间表、真题用法、模考安排、考场流程、常见误区、5.5→6.5→7.5 瓶颈、复议时间线、雅思 vs 托福/PTE | `#/inspire/ielts/article[/<id>]` |
| 核心词库 | **1000+ 雅思核心词**（听力场景 / 阅读学术 / 写作高频 / 口语高频四类），每条含英式音标、带词性的中文释义、原创英文例句 + 精准翻译 | `#/inspire/ielts/words` |

**与原有功能打通的细节**：
- 单词学习页支持 **词库切换（雅思核心 / 通用 / 全部）** 与 **四类用途筛选**，筛选结果决定「今日新词」从哪抽；还可以调整每日新词数量、按关键词搜索、按未掌握/已掌握过滤、导出当前筛选为 CSV。
- 完成一节课（≥60 分）与完成一个单词，都会按原有规则发金币（学习类每日上限 0.6）。
- 文章「标记已读」写入 `reads` 表，与「已读满 4 篇」的**阅读套餐 +0.5 金币**、晨间套餐 +1 金币联动；收藏也计入阅读套餐条件。
- 语料采用**增量安装**：`contentVersion` 从 1 升到 2 时自动补装，**保留你的学习进度、单词分配、收藏与做题得分**；「设置 → 维护操作 → 重新安装雅思语料」可手动重装。

## 四、本地开发

```bash
# 1) 安装依赖（需要 Node 18+）
pnpm install        # 或 npm install

# 2) 生成图标（可选，仓库已包含生成好的图标）
python scripts/gen-icons.py

# 3) 启动开发服务器
pnpm dev            # http://localhost:5173

# 4) 生产构建 + 本地预览 + 体积体检
pnpm build          # 类型检查 + 构建
pnpm preview
pnpm size           # 体积报告（gzip 门禁 500KB）
```

自带自检脚本（无需浏览器）：

```bash
pnpm check          # = typecheck + check:date + check:rules
pnpm check:date     # 农历换算 396 组往返一致性 + 节气/节日对照 + 日期算术
pnpm check:rules    # 金币档位（0/1–15/16–30/31+）、每周封顶 14、组合技额度、8 株植物周期与待办标题
```

> 本地预览时 `http://localhost` 属于安全上下文，Service Worker 与通知权限均可正常测试。

## 五、部署到 Vercel（永久链接，永不变更）

### 1. 代码托管到 GitHub 私有仓库

```bash
cd yue-workbench
git init
git add .
git commit -m "feat: 月月的工作台 v10.0 · 像素森系 PWA"
git branch -M main
git remote add origin git@github.com:<你的用户名>/yue-workbench.git   # 私有仓库
git push -u origin main
```

### 2. 连接 Vercel

1. 打开 <https://vercel.com/new> → **Import Git Repository** → 选择 `yue-workbench`（私有仓库需授权）。
2. Framework Preset 选择 **Vite**（仓库已含 `vercel.json`，构建命令与输出目录会自动识别）。
3. **Settings → Environment Variables** 填入下面第 6 节的变量（本地模式可先跳过）。
4. Deploy。

产出永久链接：

```
https://yue-workbench.vercel.app
```

> 之后每次 `git push` 都会自动触发构建与发布，**链接永久不变**，数据与代码完全分离（数据在你的设备 IndexedDB 与 Supabase 中，不在代码里）。

### 3. 添加到 iPhone 主屏幕

1. 用 **Safari** 打开 `https://yue-workbench.vercel.app`；
2. 点底部「分享」→「**添加到主屏幕**」；
3. **从主屏幕图标打开**（这一步是 iOS 允许系统级推送的前提），在「设置 → 推送提醒」里点「开启系统级推送」；
4. 之后锁屏即可收到提醒。

## 六、环境变量（Vercel → Settings → Environment Variables）

| 变量 | 用途 | 是否必填 |
|---|---|---|
| `VITE_SUPABASE_URL` | Supabase 项目地址 | 云端同步时必填 |
| `VITE_SUPABASE_ANON_KEY` | Supabase 匿名密钥（前端可见，受 RLS 保护） | 云端同步时必填 |
| `SUPABASE_SERVICE_ROLE_KEY` | **仅服务端函数使用**（定时推送、订阅入库），绝不下发前端 | 服务端推送时必填 |
| `VAPID_PUBLIC_KEY` | Web Push 公钥 | 系统级推送必填 |
| `VITE_VAPID_PUBLIC_KEY` | 同上（前端读取） | 系统级推送必填 |
| `VAPID_PRIVATE_KEY` | Web Push 私钥（仅服务端） | 系统级推送必填 |
| `VAPID_SUBJECT` | 形如 `mailto:you@example.com` | 系统级推送必填 |
| `CRON_SECRET` | 保护定时任务接口 | 建议填写 |
| `GOLD_API_KEY` | 可选，metals.dev 金价源；不填则用免密钥源 | 可选 |

生成 VAPID 密钥：

```bash
pnpm vapid      # 或 node scripts/gen-vapid.mjs
```

**不配置任何变量也能用**：应用会以「本地优先」模式运行，数据永久保存在设备 IndexedDB，并支持导出 JSON / CSV。

## 七、Supabase 配置（数据库 + Storage + RLS）

1. 新建项目 → 复制 **Project URL** 与 **anon key** 到 Vercel 环境变量；
2. **SQL Editor** → 粘贴执行 `supabase/migrations/0001_init.sql`：
   - 建 22 张业务表（`todos` / `plants` / `plant_logs` / `transactions` / `reminders` / `coins`…）+ `push_subs` 订阅表；
   - 结构：`id / user_id / payload jsonb / created_at / updated_at`，业务字段放在 `payload` 里，**表结构升级不会破坏已存数据**；
   - 对高频字段建生成列与索引（`date` / `kind` / `amount` / `title` / `next_due`…）；
   - **RLS 行级安全**：每张表四条策略，`auth.uid() = user_id`，只能读写自己的数据；
   - Storage 桶 `workbench`（公共读、单文件 ≤ 1MB、仅图片 MIME），写入策略限定 `<user_id>/` 目录；
   - `schema_migrations` 记录迁移版本。
3. 在应用「设置 → 数据存储与云端」中注册/登录账号，即自动切换为云端同步（本地已有数据会合并上去，不丢）。

后续迁移：新增 `supabase/migrations/0002_xxx.sql` 并执行即可，前端字段演进不需要动表结构。

## 八、系统级推送链路

```
用户点「开启系统级推送」
  └─ Notification.requestPermission()                ← 授权
  └─ navigator.serviceWorker.register('/sw.js')      ← Service Worker
  └─ PushManager.subscribe({ applicationServerKey }) ← VAPID 公钥订阅
  └─ POST /api/push/subscribe                        ← 订阅对象存 Supabase

服务端推送（网页关闭也能收到）
  ├─ /api/cron/daily          每天 06:00(北京) 推送今日待办 + 植物养护摘要，并顺带跑一遍提醒检查
  ├─ /api/cron/monthly-backup 每月 1 日提醒导出备份
  └─ /api/cron/reminders      提醒检查（手动/定时均可调用；Pro 计划可挂 */15 * * * * 实现每刻钟精确推送）
        └─ web-push.sendNotification(...)            ← VAPID 私钥签名
              └─ Service Worker 'push' 事件 → showNotification() → 锁屏可见
                    └─ 点击通知 → 打开对应页面
```

> Vercel **Hobby 计划只允许 2 条 Cron 且每天最多跑一次**，因此默认只挂了 `daily` 与 `monthly-backup`，
> 提醒检查被合并进 `daily`。升级 Pro 后，在 `vercel.json` 的 `crons` 里加一行
> `{ "path": "/api/cron/reminders", "schedule": "*/15 * * * *" }` 即可获得每 15 分钟的精确推送。

页面在前台时另有一套本地调度（每 60 秒检查一次），保证「提前 N 天」「当天到点」都能及时提醒。

## 九、数据安全与隐私

- **全站 HTTPS**（Vercel 自动签发），启用 HSTS；
- **CSP**：`default-src 'self'`，仅放行 Supabase 与金价接口，禁 `object-src`；
- **XSS 过滤**：所有用户输入统一经 `esc()`；富文本经 `sanitizeRich()` 白名单净化，剥离脚本、事件属性与 `javascript:` 协议；
- **RLS**：即便 anon key 泄露，也只能访问自己 `auth.uid()` 的行；
- **密钥隔离**：Service Role / VAPID 私钥只在 Vercel 服务端环境变量中，浏览器永远拿不到；
- **图片压缩**：上传前统一压缩为 WebP，单张 ≤ 200KB，列表只加载缩略图；
- **依赖审计**：CI 中执行 `pnpm audit`。

## 十、数据导出 / 备份

进入「设置 → 导出全部数据」：

- **JSON**：全部表一次性导出（含所有字段），用于完整备份与迁移；

## 十一、常见问题

**Q：一定要配置 Supabase 吗？**
不必。默认「本地优先」，数据存在设备 IndexedDB 里并申请了持久化存储，支持导出/导入。Supabase 只是让多设备同步与「网页关闭后仍能推送」成为可能。

**Q：iPhone 上收不到锁屏推送？**
iOS 要求：① 用 Safari；② 先「添加到主屏幕」；③ **从主屏幕图标打开**；④ 在应用内点「开启系统级推送」并允许通知。满足这四点即可锁屏可见。

**Q：为什么我没有配 VAPID 也能收到通知？**
那种是页面在前台时的本地通知。真正的「关掉网页也能收到」需要 VAPID + 服务端 Cron（见第八节）。

**Q：换手机数据怎么办？**
在设置里导出 JSON，在新设备登录同一 Supabase 账号（云同步），或直接导入 JSON 文件。

**Q：界面字太小/太亮？**
「设置 → 外观·护眼」里有护眼三档（暖纸 / 更暖 / 夜间深色）、字号三档、圆角与动效开关。
